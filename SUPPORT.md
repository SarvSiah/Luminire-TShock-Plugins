# Support

## Getting Help

### 1. Check Documentation

- [README.md](README.md) - Overview, installation, features
- [docs/INSTALLATION.md](docs/INSTALLATION.md) - Detailed install guide
- [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) - Development guide
- [docs/COMPATIBILITY.md](docs/COMPATIBILITY.md) - Version compatibility
- [docs/API.md](docs/API.md) - Core API reference

### 2. Search Existing Issues

- [Issues](https://github.com/SarvSiah/Luminire-TShock-Plugins/issues)
- [Discussions](https://github.com/SarvSiah/Luminire-TShock-Plugins/discussions)

Your question may already be answered.

### 3. Ask the Community

- **GitHub Discussions**: For questions, ideas, show-and-tell
  - https://github.com/SarvSiah/Luminire-TShock-Plugins/discussions

- **TShock Discord**: For TShock-specific questions
  - https://discord.gg/C2wrTcJ
  - Channels: #support, #plugin-dev

### 4. Open an Issue

If you found a bug or have a feature request:

- **Bug Report**: Use template `.github/ISSUE_TEMPLATE/bug_report.yml`
- **Feature Request**: Use template `.github/ISSUE_TEMPLATE/feature_request.yml`

Please include:

- TShock version (`6.1.0`)
- Plugin version
- .NET version (`dotnet --info`)
- Steps to reproduce
- Logs

## Supported Versions

Only latest release is supported for help. Please update before asking for support.

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅ Yes    |

TShock 6.1.0 / Terraria 1.4.5.6 / .NET 9.0 only.

- Issues: Typically within 1-3 days

- Security: Within 48 hours (see SECURITY.md)

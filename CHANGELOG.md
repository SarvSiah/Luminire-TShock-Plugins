# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added
- Initial repository scaffold for TShock 6.1.0
- Luminire.Core shared library
- Luminire.Essentials plugin (clear, back, join messages)
- Luminire.Template starter template
- GitHub Actions build & release workflows
- Documentation (README, CONTRIBUTING, DEVELOPMENT, INSTALLATION)

### Changed
- Target .NET 9.0 for TShock 6.1 compatibility
- Use TShock 6.1.0 NuGet package
- OTAPI 3.3.11, Terraria 1.4.5.6, ApiVersion 2.1

### Fixed
- N/A (initial release)

## [1.0.0] - 2026-08-27

### Added
- First public release
- Support for TShock 6.1.0 / Terraria 1.4.5.6 / .NET 9.0
- Essentials plugin with basic commands
- Template plugin for community
- Core library with ConfigBase, logging, extensions
- MIT License
- Full documentation and CI/CD
